# Vivaldi — время звучит

Одностраничное цифровое эссе о Вивальди. Страница собрана как единое полотно: сквозная графика, типографические сцены и управляемые прокруткой изменения масштаба и положения. Сезоны переключаются кнопками, точками и горизонтальным свайпом.

## Запуск

Откройте `index.html` через локальный HTTP-сервер. Сборка и JavaScript-зависимости не нужны. MP3-фрагменты длительностью 50 секунд хранятся в `media/` и работают с мобильными браузерами.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` публикует корень репозитория при push в `main`. В Settings → Pages → Build and deployment выбран источник **GitHub Actions**.

## Музыка и лицензии

50-секундные MP3-фрагменты первых частей четырёх концертов Вивальди, исполнение скрипача John Harrison. Локальные копии перекодированы из Ogg-записей Wikimedia Commons. Все четыре исходных файла размещены там под CC BY-SA 4.0; MP3-фрагменты распространяются на тех же условиях. Полная атрибуция и ссылки на каждый файл — в [LICENSES.md](LICENSES.md).
