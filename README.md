# Vivaldi — четыре времени

Одностраничное цифровое эссе о Вивальди, написанное на HTML, CSS и JavaScript. Мобильная композиция задумана первой; сезонная сцена управляется касанием, стрелками и точками.

## Разработка

Откройте `index.html` напрямую или используйте локальный HTTP-сервер. Проект не требует сборки и сторонних JavaScript-зависимостей.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` публикует корень репозитория при каждом push в `main`. В Settings → Pages → Build and deployment должен быть выбран **GitHub Actions**.
