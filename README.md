## Единая модель таймлайна

`story.mjs` связывает исторические события, главы, внутренние состояния, навигационные позиции и музыкальную программу. HTML-индекс используется только для нумерации глав, не для дат.

Геометрия каждой закреплённой сцены и её читаемой области измеряется после загрузки, изменения размеров, загрузки шрифтов и изменений, обнаруженных ResizeObserver. Текущая глава выбирается по фактической видимости сцены и текста в окне. Небольшой гистерезис предотвращает дрожание на границе. Разные события 1741 и 1926 имеют разные scene/state и навигационные цели; их уже раздельные контейнеры сохранены.

Подсветка даты, конечная точка заполнения и маркер получают один вычисленный event. На тематических главах удерживается последняя достигнутая дата, подпись явно обозначает тематическую сцену. Линия не продолжает самостоятельно идти к будущей дате. Координаты событий находятся на фактической SVG-кривой по X, а не по приблизительной доле её длины. Короткий общий переход маркера и линии — Web Animations, 110 мс; быстрый разворот отменяет устаревшее движение. Уменьшение движения отключает переход.

Навигация по датам использует ту же модель и измеренную геометрию, включая внутренний phase. После загрузки страницы с якорем или восстановления прокрутки состояние пересчитывается без принудительного возврата наверх.

## Художественные технологии

- Существующие SVG-траектории, CSS masks, clip-path, transform и локальные sticky-сцены.
- Новые сцены: приостановленные Web Animations с прокруткой через `currentTime`; контрапункт двух инструментов и перспективное перелистывание трёх листов. Нет независимых анимационных циклов для этих сцен.
- SVG-геометрия и общий WAAPI-переход навигационного маркера/линии.
- Canvas 2D только в активных сезонах; ограниченная плотность частиц.
- Существующий Web Audio API, два HTMLAudioElement, контролируемое перекрёстное затухание 600 мс и анализатор для сдержанных реакций света.
- Нативные ES modules для отделения модели от визуального движка. Без npm-зависимостей и сборки. WebGL и сторонние анимационные библиотеки не добавлены: для текущих образов они не дают оправданного выигрыша.

Все новые эффекты имеют уменьшенное движение; основной текст не зависит от завершения анимации. Ресурсы локальны, лицензии и исторические источники — [LICENSES.md](LICENSES.md).

## Проверка и публикация

`node qa/story-model.test.mjs` проверяет модель на четырёх десктопных высотах. `qa/mobile-check.html` — браузерные группы адаптива, независимая сверка с реальными DOM-прямоугольниками, прямой/обратный проход, переходы по датам, быстрый разворот 1741↔1926 и фактический аудиомаршрут. Результаты и ограничения — [QA.md](QA.md).

GitHub Actions `.github/workflows/deploy.yml` публикует корень при push в main. История сохраняется, force push не используется.
