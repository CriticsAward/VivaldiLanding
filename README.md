# Vivaldi — живая композиция

Короткое интерактивное повествование из шести эпизодов: пролог → Венеция и Красный священник → скрипка и оркестр → четыре времени года → забвение и возвращение → эпилог.

## Архитектура сцен

Каждый `.episode` владеет своей `.stage` и графикой. Закреплённая сцена находится внутри своего контейнера, а четыре сезона используют **одну** сцену и четыре взаимоисключающие текстовые композиции. Высота музыкального контейнера не складывается с дополнительной полноэкранной rail-сценой: старый источник переполнения удалён. Глобальных портрета, рукописи, Canvas или освещения над текстом страницы больше нет.

Прокрутка нативная. Один запланированный `requestAnimationFrame` обновляет только видимые эпизоды. Геометрия измеряется при загрузке/изменении размера, не в каждом кадре. Canvas работает только внутри музыкальной части; детализация ограничена. Уменьшение движения отключает пространственные трансформации и частицы, сохраняя доступ ко всем состояниям.

## Драматургия

- Пролог: портрет приближается, имя смещается, струна ведёт дальше.
- Венеция: историческая панорама раскрывается через арку; архитектурная перспектива становится нотным станом.
- Концерт: отдельная скрипка движется навстречу группе инструментов; траектории передают вступление солиста и ответ оркестра.
- Сезоны: рукопись превращается в четыре пластических состояния; растительные движения сменяют гроза, осеннее кружение и ледяная структура.
- Возвращение: разнесённые фрагменты рукописи сходятся в лист, свет и музыкальная линия возвращаются.
- Эпилог: портрет из начала становится камерным медальоном, линия замыкает путь.

Общая длина — около 11,15 высот экрана. Время просмотра не ограничивается: ориентир 2–3 минуты с чтением, без принудительных пауз и перехвата прокрутки.

## Музыка

Один пользовательский переключатель разрешает звук. Затем актуальный сезон выбирается по прогрессу закреплённой музыкальной сцены с гистерезисом у границ. Два HTMLAudioElement и Web Audio GainNode обеспечивают переход длительностью 600 мс. Токен запроса отменяет устаревшие обещания `play()` и отложенные остановки при быстром развороте прокрутки. При выходе музыка затихает, при возвращении возобновляется, если звук разрешён. Ошибки сбрасывают состояние кнопки и предлагают повторную попытку.

Аудио хранится локально в `media/`; атрибуция — [LICENSES.md](LICENSES.md). [QA.md](QA.md) содержит фактические проверки и ограничения.

## Запуск и публикация

Статические HTML/CSS/JS, сборка не требуется. Запуск через HTTP-сервер из корня. Существующий `.github/workflows/deploy.yml` публикует корень в GitHub Pages при push в `main`. История прошлых версий сохранена.
