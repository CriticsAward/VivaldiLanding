# Vivaldi — живая композиция

Короткое интерактивное повествование из семи сцен: пролог → Венеция и Красный священник → скрипка и оркестр → четыре времени года → наследие разных лет → забвение и возвращение → эпилог.

## Архитектура сцен

Каждый `.episode` владеет своей `.stage` и графикой. Закреплённая сцена находится внутри своего контейнера, а четыре сезона используют **одну** сцену и четыре взаимоисключающие текстовые композиции. Высота музыкального контейнера не складывается с дополнительной полноэкранной rail-сценой: старый источник переполнения удалён. Глобальных портрета, рукописи, Canvas или освещения над текстом страницы больше нет.

Прокрутка нативная. Один запланированный `requestAnimationFrame` обновляет только видимые эпизоды. Геометрия измеряется при загрузке/изменении размера, не в каждом кадре. Canvas работает только внутри музыкальной части; детализация ограничена. Уменьшение движения отключает пространственные трансформации и частицы, сохраняя доступ ко всем состояниям.

## Драматургия

- Пролог: портрет приближается, имя смещается, струна ведёт дальше.
- Венеция: историческая панорама раскрывается через арку; архитектурная перспектива становится нотным станом.
- Концерт: отдельная скрипка движется навстречу группе инструментов; траектории передают вступление солиста и ответ оркестра.
- Сезоны: рукопись превращается в четыре пластических состояния; растительные движения сменяют гроза, осеннее кружение и ледяная структура.
- Наследие разных лет: рукописи раскрываются веером, скрипка и световые голоса Gloria связывают инструментальную, оперную и духовную музыку. Обзор предшествует 1741 году; Gloria прямо обозначена как более раннее сочинение.
- Возвращение: разнесённые фрагменты рукописи сходятся в лист, свет и музыкальная линия возвращаются.
- Эпилог: портрет из начала становится камерным медальоном, линия замыкает путь.

Общая длина — около 11,15 высот экрана. Время просмотра не ограничивается: ориентир 2–3 минуты с чтением, без принудительных пауз и перехвата прокрутки.

## Музыка

Семь локальных MP3 сопровождают весь путь. После первого явного нажатия звук начинается в текущем эпизоде, включая пролог:

| Эпизод | Произведение |
|---|---|
| Пролог и Венеция, включая Pietà | La Follia, RV 63 |
| Скрипка и оркестр | Концерт для двух скрипок ля минор, RV 522 |
| Четыре сезона | Прежние фрагменты RV 269 → RV 315 → RV 293 → RV 297 |
| Наследие, возвращение и эпилог | Domine Deus из Gloria, RV 589 |

Одна кнопка сохраняет выбор звука в ходе просмотра. Камерный якорь и гистерезис стабилизируют смену музыкального эпизода. Внутри сезонов сохраняется их собственный гистерезис. Два HTMLAudioElement и Web Audio GainNode обеспечивают перекрёстное затухание 600 мс; одно произведение продолжается без перезапуска на границах пролог/Венеция и возвращение/эпилог. Токены отменяют устаревшие запросы и отложенные остановки при быстром развороте прокрутки. При сворачивании страницы звук затихает, при возвращении возобновляется, если разрешён. Ошибка воспроизведения сбрасывает кнопку и предлагает повторную попытку.

Pietà остаётся вторым состоянием Венеции. Gloria начинается в коротком обзоре наследия перед последними годами и продолжается через возвращение к финалу. Общая длина сохранена: 1115svh (при коротком экране действует минимальная высота сцены для читаемости). Финал: «Три столетия спустя. Музыка звучит».

## Временная струна

От 1024 CSS-пикселей закреплена нижняя навигация из пяти исторических точек: 1678, 1703, 1725, 1741, XX век. Кривая струна прорисовывается по прокрутке; текущая дата выделена через `aria-current`. Кнопки доступны клавиатурой; подписи открываются при наведении и фокусе. Нажатие перемещает к нужному состоянию сцены, включая находку рукописей. Тематические главы не получают вымышленных дат: над шкалой показано название главы. На узком экране остаётся компактный индикатор восьми смысловых шагов. Геометрия навигации кешируется вместе со сценами, постоянного анимационного цикла нет.

Сведения о конкретных записях, фрагментах и лицензиях — [LICENSES.md](LICENSES.md). Фактические проверки — [QA.md](QA.md). Хеши и результаты декодирования всех файлов — [qa/audio-files.json](qa/audio-files.json).

## Запуск и публикация

Статические HTML/CSS/JS, сборка не требуется. Запуск через HTTP-сервер из корня. Существующий `.github/workflows/deploy.yml` публикует корень в GitHub Pages при push в `main`. История прошлых версий сохранена.
